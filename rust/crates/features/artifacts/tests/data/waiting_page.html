Choose how often the export job runs

The export job stays paused until it has an interval, because the table it fills changed shape and no run is safe yet.

1 Run the export every hour, or once a day?

  • 「Hourly」: run the export every hour, and the table stays at most an hour old.
  • 「Once a day」: run the export at 02:00, and the table stays at most a day old.

Recommendation: 「Once a day」, at 02:00, when the database is idle.

Tradeoff: hourly runs keep the table fresher, but they read the database 24 times a day.

Full story, expand to check the recommendation by hand
  • A run reads the whole table and takes about 9 minutes.
  • Worked example: hourly runs occupy 216 minutes a day; a daily run occupies 9 minutes.
