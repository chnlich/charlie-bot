What the deadline column means. The clock starts at a blocked→direct transition this panel saw with its own probe, which means a cache entry had just been written only if you renewed through the browser enrollment flow. Signing in with an Okta SSH CA certificate bypasses the cache entirely and makes the number wrong. The figure is an upper bound in the other direction too: a login pod restart wipes the cache early, so the real deadline is never later than shown and can be sooner.
