1 Goal

Hovering this paragraph in a rendered artifact should show a non-layout-shifting highlight and a comment affordance.

Submitting a note should append a structured artifact comment to the chat composer without sending it.

2 Blocks

Expected

  • Each list item can be selected as its own block.
  • Table cells and code blocks are also valid anchors.

Not Expected

  • The hover state should not resize the artifact.
  • The note should not auto-send.
