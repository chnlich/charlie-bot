5Methodology

  • Sources: Claude Code reads each assistant message's usage from projects/**/*.jsonl in every config dir; Codex reads token_count events from sessions/**/*.jsonl in every home, with the model name taken from the same file’s turn_context; opencode reads the message table of its local database. All three are local logs; no vendor usage API is called.
  • Dedupe: Claude Code replays history verbatim on resume / fork, so responses are deduped on message.id.
  • Codex cumulative totals are not additive: subagent threads inherit the parent’s total_token_usage, so summing across files double counts; the per-request last_token_usage is summed instead, and the cumulative value only cross-checks root sessions.
  • Not covered: Gemini (gemini_api_key direct) has no local token log; any call made on another machine, or outside the config dirs / codex homes registered in config.yaml, is not in this table.
  • Retention: the left edge {{ window[0] }} is the date of the oldest local log file, not an account start date; earlier sessions that have been pruned cannot be counted.
  • Cost: this reports tokens only and does not convert to money — these calls run on subscriptions, not per-token.
