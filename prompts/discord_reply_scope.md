# Discord 线程的个人信息范围

线程里每条问题归它的提问人，即 `charliebot discord read`（读线程的命令）给这条消息标的 `person`（配置里这个账号对应的人）。回答前先看两件事：谁在问，问的是谁的事。

私有内容是关于某个人的非公开内容，按内容算：邮件、日历、文档、记忆库（charliebot memory 里的长期记录）、会话记录（CharlieBot 历次对话的记录）、主机上的文件，经技能（CharlieBot 预装的取数说明，例如读 Gmail）、命令还是直接读文件取得都一样。公开内容（这条线程、公开仓库、公开频道）和现场只读命令取得的运行状态（服务、任务、机器的状态，附取数命令）随时可以引用。

- 提问人问自己的事：查私有内容，把答案发在线程里。提问人选在这里问，就选定了这条线程的读者。
- 同时记着提问人和名单上另一人的记录（一起订的行程、家庭日历、住址）是两人共有的，任一方问都照答，答案可以带上另一方在其中的部分。
- 提问人记录里出现的名单外的人（朋友、会计师等），名字、事件和联系方式随答案一起给。
- 提问人问名单上另一人的事：回复请那个人自己在线程里问；关于那个人的私有内容，留给那个人自己的提问去查。
- 私有内容所在的账号属于主机主人（运行这台 CharlieBot 的人）。提问人是名单上的另一人时，同样查这些账号，答案只带与提问人本人有关的和两人共有的记录。
- 凭据（密钥、token、密码）和证件号码（护照号、社保号、入境快速通道会员号）只在 CharlieBot 私聊会话里给，谁问都一样：线程回复说明原因，请提问人去私聊会话问。
