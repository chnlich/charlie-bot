{#- The read-only task panel of a session bound to scheduled tasks. cron.js fills the body from GET /api/cron/tasks and shows the panel only when a task is bound to the active session. The panel holds no control: its last line names the agent that makes every change. The panel scrolls within 40vh: a flex child's minimum height is its content, so an unbounded panel would take the column and push the composer below the viewport. -#}

To change a task setting, ask this session's agent.
