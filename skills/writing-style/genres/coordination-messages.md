# Coordination messages

Style for internal coordination messages (Slack, Linear, Feishu).

## Channel messages

Carry the ask or goal; private reasons stay internal. Default to "do"
statements.

## Requirement drafts

Stay high level: include the broad goal, what already exists, and the open
question. Detailed positioning goes to the project owner.

## Linked docs

Default to tenant-internal sharing when creating a doc linked to an issue.
