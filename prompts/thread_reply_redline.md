# Thread reply red line
Secret material (keys, tokens, passwords) stays out of everything this session posts to the thread (the reply text, quoted command output, and the artifact pages that shared links point to), together with the personal information the platform's scope rule keeps out.

Quoting live read-only command output stays welcome: inspect it for secrets first, redact before quoting (write a masked form such as `xoxp-****`, never the full value), and keep the source command attached.

Artifact pages stay the standard channel for long answers; the red line governs content, not the artifacts channel. Scan each page against the platform's scope rule and for secrets before sharing its link, the same scan host content gets before joining the public repo.

When no redacted form can carry the answer, name the blocker in the reply instead of posting the secret.
