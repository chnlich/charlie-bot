5Methodology

  • Sources: the local-log sources ({{ ctx.usage_sources|join(', ') }}) feed a per-call ledger (usage/ledger.sqlite3 under this profile’s charliebot home): every capture — the cron job, the start of every storage-cool sweep, charliebot usage-ledger capture — upserts one record per API call into it (deduped on the CLI’s own message id), and this page reads its rows from that ledger alone, as of the last capture; loading the page captures nothing. No vendor usage API is called, and ledger rows are never deleted, so the numbers stop shrinking when the source logs they were parsed from are pruned. CLC and Antigravity usage and the fallback records come from CharlieBot’s own logs; a fallback record counts only when the CLI’s own log holds no record of the same session, so a sub-row marked (fallback) is a lower bound.
  • Last week and time zone: last week is the Pacific calendar week [Monday 00:00, next Monday 00:00) in America/Los_Angeles, the week before the one the page was rendered in. Every date and stamp on the page is in that zone, marked PDT or PST; a week that crosses the clock change runs 169 hours.
  • Dedupe: Claude Code replays history verbatim on resume / fork, so responses are deduped on message.id.
  • Codex cumulative totals are not additive: subagent threads inherit the parent’s total_token_usage, so summing across files double counts; the per-request last_token_usage is summed instead, and the cumulative value only cross-checks root sessions.
  • Not covered: backend types with no collection rule here (gemini) are not in this table — their per-run usage lives only in the thread event logs stored beside each session’s threads. Gemini (gemini.api_key direct) has no local token log; any call made on another machine, or outside the Claude login directories listed under accounts.claude in config.yaml, or the default ~/.codex home, is not in this table either.
  • Retention: each source’s history is anchored at its first native record (the CLI’s own log){% for src in ctx.usage_sources %}{% set ns = ctx.per_src[src].get('native_start', '') %} — {{ src }} from {{ ns if ns else '(no native records yet)' }}{% endfor %}. The left edge {{ window[0] }} is the earliest counted record, not an account start date.
  • Cost: this reports tokens only and does not convert to money — these calls run on subscriptions, not per-token.
