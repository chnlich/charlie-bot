# README

Docs that introduce a package or a directory to its next reader.

- Name the things; leave their count out. The count restates what the list
  already shows and goes stale on the next commit that changes it. A constant
  the code itself reads is content rather than inventory: keep that.
- Give the shape before the parameters: what the thing is and how its parts relate, then what each knob does.
  A reader who has the picture can place every parameter; a parameter list alone leaves the picture to be
  reconstructed from the names.
